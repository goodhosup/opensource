# 자유 소프트웨어 vs 오픈소스

두 용어는 대부분 같은 소프트웨어를 가리키지만, **강조하는 가치가 다릅니다.**

| 구분 | 자유 소프트웨어 (Free Software) | 오픈소스 (Open Source) |
|---|---|---|
| 주창자 | 리처드 스톨먼, FSF | 에릭 레이먼드, 브루스 페런스, OSI |
| 등장 | 1983~1985 | 1998 |
| 관점 | 윤리·사회 운동: 사용자의 자유는 권리 | 실용·개발 방법론: 더 좋은 소프트웨어를 만드는 방식 |
| "Free"의 의미 | 공짜(free beer)가 아니라 자유(free speech) | 용어 자체에서 혼란을 제거 |
| 선호 라이선스 | 카피레프트(GPL 등) | 허용형(MIT, Apache)과 카피레프트 모두 |
| 독점 SW에 대한 태도 | 비윤리적인 것으로 봄 | 선택의 문제로 봄 |

## 자유 소프트웨어의 4가지 자유
- **자유 0**: 어떤 목적으로든 프로그램을 실행할 자유
- **자유 1**: 프로그램이 어떻게 동작하는지 연구하고 수정할 자유 (소스 코드 접근 필요)
- **자유 2**: 복제본을 재배포할 자유
- **자유 3**: 수정한 버전을 배포해 공동체 전체가 혜택을 누리게 할 자유

## 통합 용어
- **FOSS** (Free and Open Source Software)
- **FLOSS** (Free/Libre and Open Source Software): "Libre"로 "자유"의 의미를 분명히 함
