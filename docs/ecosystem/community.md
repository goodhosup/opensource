# 국내 오픈소스 대회·행사·커뮤니티

> 2026-10-25 기준으로 확인한 내용입니다. 일정과 세부 조건은 해마다 바뀌므로 지원 전 공식 페이지를 다시 확인하세요.

## 1. 정부 주도 대회·프로그램

### 오픈소스 개발자대회
| 항목 | 내용 (2026년 기준) |
|---|---|
| 주최 | 과학기술정보통신부 (오픈소스 포털 OSS.KR에서 운영) |
| 역사 | 오랫동안 열려 온 '공개SW 개발자대회'가 2025년 '오픈소스 개발자대회'로 이름을 바꿈 |
| 주제 | "우리의 코드 한 줄이, AI 시대의 지능을 키운다" |
| 대상 | 학생, 일반인 등 누구나 (학생부·일반부) |
| 과제 | 자유과제(AI·클라우드·보안 등), 지정과제(기업 현업 문제 해결), 사회문제해결 프로젝트 |
| 일정 | 참가 신청 ~7.17 → 출품작 제출 ~8.27 → 서면평가(결선 50개 내외) → 약 3주 전문가 멘토링 → 발표평가·시상 |
| 시상 | 총상금 6,700만 원, 23개 작품. 대상(과기정통부 장관상) 학생부·일반부 각 1,000만 원 |
| 특징 | 온라인 교육과 현업 멘토링 제공. 수상작은 라이선스·보안 검증 후 오픈소스 포털에 공개 |
| 링크 | [osscontest.kr](https://osscontest.kr/) · [OSS.KR 대회 안내](https://www.oss.kr/pages/2) |

참고: 2025년 대회는 총상금 6,100만 원이었고, 생성형 AI 등 신산업 분야 중심으로 개편됐습니다.

### 오픈소스 컨트리뷰션 아카데미
| 항목 | 내용 |
|---|---|
| 주최·주관 | 과기정통부 / 정보통신산업진흥원(NIPA), 오픈업(OpenUP) |
| 목적 | 현업 멘토와 함께 실제 오픈소스 프로젝트에 기여하며 개발 문화를 체험 |
| 과정 | **체험형**(상반기, 입문자 대상 6주): Git 활용과 프로젝트 기여 기초. 2026년에는 15개 프로젝트(Apache Airflow, Valkey, PyTorch 문서 한글화 등)<br>**참여형**(본격 기여, 약 13주): 멘토와 팀을 이뤄 국내외 프로젝트에 실제 기여. 2026년 접수 5.12~6.14, 성과공유회 시상(대상 200만 원 등) |
| 2026 체험형 일정 | 접수 3.6~4.1, 발대식 4월 중순, 활동 6주 |
| 대상 | 오픈소스에 관심 있는 예비·초급 개발자 누구나 |
| 운영 방식 | 정해진 강의가 아닌 멘토·팀과 협의한 시간에 온·오프라인 '모각코' 방식 |
| 링크 | [contribution.ac](https://contribution.ac) |

### 오픈소스 AI·SW 커뮤니티 지원 (NIPA)
- 2026년 공모로 **개발자 커뮤니티 15곳**을 선정해 지원 (발대식 2026.7.25)
- 지원 내용: 국내외 오픈소스 컨퍼런스·세미나 참가, 클라우드 GPU·서버 자원, 오픈업 센터 등 협업 공간
- 분야: AI·머신러닝, 생성형 AI, 데이터 엔지니어링, 클라우드 인프라, 오픈소스 DB, 파이썬, 보안

### 오픈업(OpenUP) 센터
NIPA가 운영하는 오픈소스 지원 브랜드이자 공간입니다. 기술지원, 라이선스·보안 검증, 교육, 커뮤니티 활동 공간을 제공합니다. → [OSS.KR](https://www.oss.kr)

## 4. 참여 방법 추천
1. **입문**: 컨트리뷰션 아카데미 체험형 → 문서 번역·오타 수정 같은 작은 기여부터
2. **실력 쌓기**: 컨트리뷰션 아카데미 참여형, 관심 분야 커뮤니티(파이토치, 쿠버네티스 등) 활동
3. **성과 내기**: 오픈소스 개발자대회 출품, 커뮤니티 행사 발표
4. **최신 동향**: 테크데이, 오픈소스 서밋 코리아 참석, OSS.KR 뉴스레터 구독
