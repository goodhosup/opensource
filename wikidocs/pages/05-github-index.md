GitHub는 세계 최대의 오픈소스 협업 플랫폼입니다. 이 장은 **기여자**로서 다른 프로젝트에 참여하는 방법과, **메인테이너**로서 내 프로젝트를 운영하는 방법을 함께 다룹니다.

[[TIP("📝 이 장에서 다루는 것")]]
- 계정과 저장소 기본
- 오픈소스 기여 워크플로 (포크 → 브랜치 → PR)
- 이슈, 풀 리퀘스트, 코드 리뷰
- 저장소 운영과 협업 설정 (브랜치 보호, 템플릿, 릴리스)
- GitHub Actions로 자동화 (CI/CD)
- GitHub Pages로 문서 사이트 발행
- 보안 기능
- GitHub CLI (`gh`)
[[/TIP]]
## GitHub 핵심 용어
| 용어 | 설명 |
|---|---|
| Repository (저장소) | 프로젝트의 코드, 이력, 이슈, 설정을 담은 단위 |
| Fork (포크) | 다른 사람의 저장소를 내 계정으로 복제. 쓰기 권한 없이 기여할 때 사용 |
| Pull Request (PR) | 내 브랜치의 변경을 다른 브랜치에 병합해 달라는 요청과 리뷰 공간 |
| Issue (이슈) | 버그, 기능 제안, 질문을 기록하고 논의 |
| Discussions | 질문·아이디어·공지를 위한 포럼형 공간 |
| Actions | 저장소 이벤트에 반응해 빌드·테스트·배포를 자동 실행 |
| Pages | 저장소 내용을 정적 웹사이트로 무료 호스팅 |
| Projects | 이슈와 PR을 칸반·표 형태로 관리하는 보드 |
| Organization | 여러 사람이 저장소를 함께 소유·관리하는 조직 계정 |
