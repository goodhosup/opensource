# 오픈소스 핸드북

**오픈소스의 개념과 라이선스부터 Git·GitHub 실전 사용법, 국내 정책과 커뮤니티, AI 시대의 향후 방향까지** 한 권으로 정리한 한글 안내서입니다.

## 구성

| 부 | 내용 |
|---|---|
| 1부. 오픈소스의 개념 | 정의와 원칙, 역사, 자유 소프트웨어와의 차이, 주요 용어, 장점과 한계 |
| 2부. 라이선스 | 라이선스 분류와 의무, 호환성, 소스 어베일러블, 실무 체크리스트 |
| 3부. Git 사용법 | 설치와 설정, 기본 명령, 브랜치, 원격 저장소, 되돌리기, 고급 기능, 요약표 |
| 4부. GitHub 운용 방법 | 기여 워크플로, 이슈·PR·리뷰, 저장소 운영, Actions, Pages, 보안, GitHub CLI |
| 5부. 생태계와 커뮤니티 | 재단과 프로젝트, 비즈니스 모델, 국내 대회·행사·커뮤니티 |
| 6부. 향후 방향 | 보안과 공급망, 지속가능성, 정책, AI가 미치는 영향 |
| 부록 | 국내 정책·지원 사이트와 참고 자료 |

정책·행사 정보는 2026년 10월 25일 기준이며 각 페이지에 출처를 달았습니다.
